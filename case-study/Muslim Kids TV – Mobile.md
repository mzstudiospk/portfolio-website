# Muslim Kids TV – Mobile Application Case Study

## Overview

Developed and maintained a cross-platform streaming mobile application available on both **Google Play Store and Apple App Store**.

The app delivers video content for children with a focus on performance, stability, and smooth user experience.

---

- React Native development for iOS & Android
- API integration for dynamic content
- Performance optimization
- Production build & release management
- Bug fixing & stability improvements

---

## Key Features

- Video streaming workflows
- Content-based navigation
- Optimized media loading
- Responsive UI for multiple screen sizes
